# SillyBilibili

> 一个用于扫描、管理、播放与导出本地 B 站离线缓存的视频工具。

SillyBilibili 面向已经下载到手机本地的 B 站缓存：帮助你找到缓存视频、按自己的方式整理，并在不转换的情况下直接播放；需要通用文件时，也可以导出为 MP4。

## 功能概览

| 模块 | 能做什么 |
| --- | --- |
| 缓存扫描与管理 | 扫描 B 站缓存目录，自动识别视频、封面、时长与分辨率；支持模糊搜索、筛选、排序、分类和批量整理。 |
| 本地播放器 | 直接播放缓存的音视频分轨文件或已导出的 MP4；支持选集、全屏、竖屏适配、上下滑切换、双击播放/暂停、左右滑动快进/回退。 |
| 后台播放 | 可在设置中开启后台播放，离开播放页后通过底部迷你播放器返回或关闭播放。 |
| MP4 导出 | 将缓存重封装为 MP4，提供前台/后台进度反馈；导出后可在「已导出」中继续搜索、筛选和管理。 |
| 分类管理 | 新建、重命名、删除分类；长按视频进入多选后，可把多个视频加入指定分类。 |
| 原视频状态 | 依据缓存中的 BV 号查询原视频状态，并在卡片与播放页显示「在线」「已下架」「暂无法核验」等结果。 |
| 文件完整性 | 可执行完整性检测，并以状态标签提示媒体文件是否仍可读取。 |
| 多语言 | 支持简体中文与 English，默认使用简体中文。 |

## 快速开始

1. 先在 B 站客户端中下载需要管理的视频。
2. 打开 SillyBilibili 的「扫描」页，确认或选择 B 站缓存目录后开始扫描。
3. 如果系统提示目录受隔离保护，按下方说明完成 Shizuku 授权，再重新扫描。
4. 扫描结束后，在「首页」搜索、筛选、分类或长按多选视频；点按任意视频卡片即可直接进入播放页。
5. 需要普通视频文件时，在播放页点「转换为 MP4」，随后到「已导出」页管理或打开导出的文件。

## 功能入口

| 入口 | 主要用途 |
| --- | --- |
| 首页 | 浏览已扫描的视频；切换卡片/网格视图，搜索、筛选、排序和分类。长按视频可进入批量选择。 |
| 已导出 | 查看、搜索、筛选、分类、打开或删除已导出的 MP4。 |
| 扫描 | 配置缓存目录、查看扫描进度和结果，并重新扫描以同步源文件的增删变化。 |
| 设置 | 开关后台播放、切换语言、手动刷新原视频状态、管理分类与查看使用指南。 |
| 播放页 | 播放视频、选集、调整倍速、全屏、设置定时停止、转换 MP4，并查看原视频状态与文件信息。 |

## Shizuku 配置（重点）

Android 的存储隔离可能阻止应用直接读取 B 站的私有缓存目录。目录未被隔离时，无需配置 Shizuku；只有扫描提示无法访问缓存目录时，才需要配置。

### Android 11 及以上：无线调试启动

1. 安装并打开 [Shizuku](https://shizuku.rikka.app/)。
2. 在手机「设置 → 关于手机」连续点击版本号，启用开发者选项。
3. 进入「开发者选项」，开启「无线调试」；在 Shizuku 中选择通过无线调试启动。
4. 按 Shizuku 的配对提示完成配对并启动服务。
5. 回到 SillyBilibili，在扫描页或设置页点击 Shizuku 授权，同意系统授权弹窗。
6. 返回「扫描」页重新开始扫描。

### Android 10 及以下：电脑 ADB 启动

1. 在开发者选项中开启「USB 调试」，手机通过 USB 连接电脑。
2. 在电脑命令行执行 Shizuku 应用显示的启动命令（命令会随 Shizuku 版本变化，请以应用内为准）。
3. 看到 Shizuku 服务已启动后，回到 SillyBilibili 授权并重新扫描。

### 常见品牌设置提示

不同系统的菜单名称略有差异：

- 小米 / HyperOS：开发者选项通常位于「更多设置」。如无线调试不稳定，检查是否开启了省电限制。
- OPPO / realme / OnePlus：开发者选项通常位于「其他设置 → 开发者选项」。
- vivo / iQOO：开发者选项通常位于「系统管理 → 关于手机」。
- 华为 / HarmonyOS：部分机型对无线调试或后台服务限制较多；若无法启动，请优先尝试电脑 ADB 方式。

重启设备后，Shizuku 服务通常需要重新启动。应用内的「设置 → 使用指南」提供同样的可展开说明，方便在手机上随时查看。

## 常见问题

### 为什么扫描不到视频？

确认视频已在 B 站下载完成，并检查扫描目录是否指向 B 站缓存目录。若页面提示访问受限，请先完成 Shizuku 配置并授权。

### 为什么视频显示“缓存文件读取失败”？

这通常表示 B 站或文件管理器已删除/清理缓存文件，或缓存目录内容发生了变化。请在「扫描」页重新扫描；已成功导出的 MP4 不受缓存清理影响。

### “暂无法核验”是什么意思？

应用没有取得足够信息完成线上状态查询，例如缓存缺少 BV 号、网络请求失败或线上接口暂不可用。它不等于视频已下架；可在「设置 → 刷新原视频状态」稍后重试。

### 封面为什么是黑的或没有显示？

应用优先使用缓存中自带的 cover 文件；找不到时会尝试从视频生成预览帧。少数损坏或不可读取的缓存无法生成预览，请重新扫描或确认文件仍存在。

## 开发与构建

默认开发分支为 `dev`。常用命令：

```powershell
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleDebug
.\gradlew.bat assembleRelease
```

构建完成后的安装包：

```text
app\build\outputs\apk\debug\app-debug.apk
app\build\outputs\apk\release\app-release.apk
```

提交会先推送至 `dev`，验证后再快进合并到 `main`；正式安装包通过 [GitHub Releases](https://github.com/NeitherTourRest/SillyBilibili/releases) 发布。
